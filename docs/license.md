## Runtime Library & Output Exception

> **What does this mean for your projects?**  
> You have 100% ownership of the binaries you create with HP-HL. You can build commercial games, proprietary systems, or closed-source enterprise software without paying any royalties or being required to include the HP-HL license notice inside your game or binary distribution.

```text
Runtime Library & Output Exception

As a special exception, if you compile source code using the HP-HL compiler
and that generated output (executable binaries, dynamic libraries, WebAssembly
modules, or intermediate code) includes or links against any portion of the
HP-HL Runtime Library (compiler/src/runtime/, runtime/, or stdlib/), this
Software does not by itself cause the resulting executable or library to be
covered by the MIT License.

You may distribute compiled binaries produced with HP-HL under terms of your
choice (commercial, proprietary, open source, or closed source) without being
```
